# BLAGO OTGRUZKI

Программа для отгрузок: утренние отчёты и «Сборка», этикетки Ozon FBS, поставки и стикеры Wildberries FBS,
связь со складом BLAGO.

Текущая версия — в [CHANGELOG.md](CHANGELOG.md), в окне программы — внизу слева.

## Установка (один раз)

```
pip install -r requirements.txt
python blago_otgruzki.py
```

Сборка в один .exe:

```
pip install pyinstaller
pyinstaller --onefile --windowed --name "BLAGO OTGRUZKI" blago_otgruzki.py
```

## Обновление

1. Скачать новый `blago_otgruzki.py` (или собрать .exe заново).
2. Положить на место старого. Настройки и ключи лежат рядом в отдельных файлах и не теряются.
3. Внизу слева в окне — новый номер версии.

## Где лежат ключи

Рядом с программой, **в репозиторий не попадают** (см. `.gitignore`):

| Файл | Что внутри |
|---|---|
| `cabinets.json` | ключи кабинетов Ozon |
| `wb.json` | токен Wildberries |
| `sklad.json` | адрес и ключ склада BLAGO |
| `morning.json` | настройки утренней сборки |
| `sklad_pending.json`, `sklad_morning.json` | что ждёт отправки на склад |

Эти файлы никому не пересылать.

## Склад BLAGO

«Настройки → Склад BLAGO»: адрес склада и ключ (на складе: Администратор → Интеграции → Ключи API).
После «Утра» и волн заказы ждут проверки — кнопка «Отправить на склад» вверху.

## Тесты

```
pip install -r requirements-dev.txt
pytest
```

Тесты не делают ни одного настоящего запроса к Ozon, WB и складу: вся сеть подменена подделками
(`tests/fakes.py`), ключи выдуманные, файлы настроек программы не читаются.
